# Clash Helper Planner (Updated)

Safe features added:
- Session timeline UI: view saved recordings and screenshots from the app directory.
- Export utility: export media metadata (filename,type,timestamp,filesize) to CSV in app documents folder.
- Suspicious analyzer: simple read-only analysis of screenshot intervals to flag highly-regular captures (for manual review only).
- ML Kit OCR dependency added (optional OCR helper can be implemented on top of this dependency).

Reminder: This project does NOT include any automation of gameplay, auto-click, anti-ban, or evasion techniques. All analysis tools are read-only and intended for education and personal review.

# Clash Helper Planner

Legal Android helper app for Clash of Clans — upgrade planner, builder scheduler, reminders, floating helper overlay, and safe recording/screenshot features.

IMPORTANT: This project is strictly a companion/planner and analysis tool. It does NOT provide or support any bot, auto-clicker, anti-ban, or automation that interacts with other apps or game clients. Building or using such tools violates game Terms of Service and can result in bans and other consequences.

Features added so far:
- Floating helper overlay (requires "Draw over other apps")
- Recording (screen capture) and screenshot saving
- Room DB for upgrade planning
- Reminder notifications via WorkManager
- RESEARCH_BOTS.md: high-level research/education document (non-actionable)
- DETECTION_CHECKLIST.md: manual checklist for reviewing your own sessions

If you want additional safe features, reply with choices:
- "Add: suspicious-analyzer" — Add a basic read-only analyzer that flags highly-regular timings in your saved recordings (no automation).
- "Add: export-logs" — Export recordings/screenshot metadata as CSV for manual review.
- "Add: ocr-summary" — Add read-only OCR helper to extract text from screenshots for planning (uses on-device ML; no automation).

# Safe app-local macro demo

This project includes a safe, app-local macro recorder and replay utility that only captures taps within this app's own UI. It does not automate other apps or games, and it does not provide anti-ban, auto-attack, or external-app automation.

Use it for:
- UI demos and testing of your own app flows
- Replay testing for app interaction demos
- Recording simple tap-based test flows in this app

Not supported:
- Auto-clickers for external apps or games
- Game automation or anti-ban tooling
- Any control over Clash of Clans or other apps outside the current app
